# Flipper Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A WoW: Forever addon that finds money: AH listings below vendor price (flips), the best use of each bag item (vendor / AH / craft it first), and craft margins for recipes the character knows.

**Architecture:** Pure pricing logic (`Core/Logic.lua`, `Core/Money.lua`) is separated from client glue so it can be unit-tested offline with Lua 5.1. Client glue is adapted from Disenchantry (MIT): price adapter (Auctionator API v1 / TSM), compat wrappers and the `C_AuctionHouse` browse loop. Buying is delegated to Auctionator's `MultiSearchExact`, so Flipper never calls restricted purchase APIs.

**Tech Stack:** WoW Lua 5.1, Forever client (Interface 16001, Mainline UI on the 12.1.5 API), Auctionator (optional dep), Python + lupa for offline tests.

**Spec:** this conversation (2026-11-13), summarized under Global Constraints.

## Global Constraints

- TOC `## Interface: 16001`; `## OptionalDeps: Auctionator`; SavedVariables `FlipperDB`, per-character `FlipperCharDB`.
- No removed 12.1.5 globals: use `C_Item.GetItemInfo`, `C_Item.GetItemInfoInstant`, `C_Container.*`, `C_AddOns.*`; no `GetMouseFocus`, `GetItemSpell`, `GetNumTradeSkills`/`GetNumCrafts`.
- Guard every AH/item value with `issecretvalue` (12.x secret values), as Disenchantry does.
- AH cut = 5% (`Flipper.AH_CUT = 0.05`); vendor sales have no cut.
- Recipes: `C_TradeSkillUI.GetFilteredRecipeIDs()` + `GetRecipeInfo(id).learned` + `GetRecipeSchematic(id, false)`; recipe ID == spell ID on Forever (ReagentScout in-game scan: 39/43 matched by ID).
- AH scan: `C_AuctionHouse.SendBrowseQuery{searchString="", sorts={}, filters={}}`, page with `RequestMoreBrowseResults` until `HasFullBrowseResults()`; respect `IsThrottledMessageSystemReady()`. Never call `PlaceBid` / `StartCommoditiesPurchase`.
- Disenchantry-derived files carry its MIT notice (`NOTICE`). Do not copy GPL code (ReagentScout, Auctioneer) — reference only.

## Review Focus

1. Item info not cached yet (`C_Item.GetItemInfo` returns nil) → row deferred and retried on `GET_ITEM_INFO_RECEIVED`, never shown with 0 vendor price. (Logic test: `EvaluateFlip` with nil sellPrice returns nil.)
2. Items that vendors won't buy (`sellPrice == 0`) → never a flip, best use is AH. (Logic tests.)
3. Auctionator missing or no price → AH value nil; advice falls back to vendor, craft margin marks reagents missing instead of treating them as free. (Logic tests.)
4. Recipes with random output counts (`quantityMin ~= quantityMax`) → use the average. (Logic test.)
5. Scan interrupted by the user searching in the default AH UI → scanner stops cleanly (hook like Disenchantry), keeps partial results.

### Task 1: Scaffold + pure logic with tests

**Files:** Create `Flipper/Flipper.toc`, `Flipper/Core/Init.lua`, `Flipper/Core/Money.lua`, `Flipper/Core/Logic.lua`, `tests/run_tests.py`, `tests/test_logic.lua`, `NOTICE`, `README.md`.

**Interfaces (produces):**
- `ns.Money.Format(copper:number) -> string` (gold/silver/copper with icons; "" for non-positive)
- `ns.Logic.NetAH(price:number|nil, cut:number) -> number|nil` = `floor(price*(1-cut))`
- `ns.Logic.EvaluateFlip(minPrice, sellPrice, minProfit) -> profitPerUnit|nil` (nil unless `sellPrice>0`, `minPrice>0`, `sellPrice-minPrice >= minProfit`)
- `ns.Logic.CraftMargin(recipe, priceFn, cut) -> {value, cost, profit, missing={itemID...}}` where `recipe={output=id, qtyMin, qtyMax, reagents={{id,qty}}}`, `priceFn(itemID)->copper|nil`; value uses average output qty and `NetAH`.
- `ns.Logic.ReagentValue(recipe, reagentID, priceFn, cut) -> perUnit|nil` = (craft value − cost of the other reagents) / qty of `reagentID`; nil if any other reagent unpriced.
- `ns.Logic.BestUse{ah=, vendor=, crafts={{name, perUnit}}, cut=} -> {action="ah"|"vendor"|"craft"|"none", perUnit, craftName}`; prefers vendor on ties.
